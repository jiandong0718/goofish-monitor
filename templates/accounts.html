首次登录（推荐）

  1. 在有图形界面的机器（本机桌面 / VNC / SSH -X）进入项目目录并激活 venv。
  2. 执行登录脚本（会强制有头浏览器，写入持久化配置）：
cd {{ project_root }}
source .venv/bin/activate
playwright install chromium   # 若尚未安装
python -m app.scripts.login_goofish
  1. 在弹出的 Chromium 中登录闲鱼，直到脚本提示成功并退出。
  2. 云主机无桌面时：在本地登录后，把 data/browser_profile/ 同步到服务器同路径。
  3. 设置 COLLECTOR_BACKEND=playwright，不要设置 GOOFISH_FIXTURE_PATH，启动服务并 resume 任务即可 24h 定时真扫。
